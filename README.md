# todo-app
シンプルなToDoリストアプリ。単一のHTMLファイルのみで動作します。

## 使い方

`todo-app.html` をブラウザで開くだけです。ビルドやサーバーは不要です。

## 主な機能

- 複数のリストを作成・管理（買い物リスト、タスクなど）
- カテゴリプリセット（買い物・優先度・ジャンル・行動ベース）をリストごとに設定
- アイテムの追加・完了切り替え・削除
- 「すべて / 未完了 / 完了」でのフィルタリング
- カテゴリごとの絞り込み
- データはブラウザの `localStorage` に自動保存

## 技術構成

- HTML / CSS / JavaScript のみ（フレームワーク・ビルドツール不使用）
- データ永続化: `localStorage`
